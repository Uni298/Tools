入力記法クイックガイド（チートシート）

分数・累乗・添え字
  • 18/a → \frac{18}{a}
  • (x+1)/(x-1) → \frac{x+1}{x-1}
  • a^2, x^(n+1) → a^{2}, x^{n+1}
  • a_1, a_(n+1) → a_{1}, a_{n+1}
ルート（平方根・n乗根）
  • sqrt(x) → \sqrt{x}
  • sqrt(a^2+b^2) → \sqrt{a^{2}+b^{2}}
  • cbrt(x) → \sqrt[3]{x}
  • root(n, x) → \sqrt[n]{x}
関数・極限・総和・積分
  • sin(x), cos(x) → \sin(x), \cos(x)
  • log(x), ln(x) → \log(x), \ln(x)
  • sum_{n=1}^infty → \sum_{n=1}^{\infty}
  • int_0^1 x^2 dx → \int_{0}^{1} ...
ギリシャ文字・比較記号
  • alpha, beta, theta → \alpha, \beta, \theta
  • pi, infty → \pi, \infty
  • <=, >=, != → \le, \ge, \neq
  • +-, ->, => → \pm, \to, \Rightarrow
ブラウザ上で完結して動作するため、入力した数式が外部サーバーに送信されることはありません。
